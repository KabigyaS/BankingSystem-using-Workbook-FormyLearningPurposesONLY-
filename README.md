# BankingSystem-using-Workbook-FormyLearningPurposesONLY-
This project was created to learn and practice Python programming and working with the openpyxl library.
It implements a simple banking system that allows users to:
-Create and manage accounts
-Deposit and withdraw money
-Transfer funds between accounts
-View transaction history
All account data is stored in an Excel workbook, making it easy to track balances and transactions. This project is for learning purposes only. It is not intended for real-world financial use and does not include security features.
